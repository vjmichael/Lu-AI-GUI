## 3. Root cause and target architecture

Avoid a ground-up rewrite. Four distinct scoped lanes (workspace/Reader/reviewed apps/utility) already share `run_supervised_native_turn_journaled_observed*` in [supervised_tool_generation.rs:527](https://github.com/vjmichael/Lu-AI-GUI/blob/11ffcbdb5a32e6aee06fb1355d3fa1561b3c5a4a/src-tauri/lu-core/src/supervised_tool_generation.rs#L527), with Protobuf/registry and model feedback in [agent_tool_loop.rs:389](https://github.com/vjmichael/Lu-AI-GUI/blob/11ffcbdb5a32e6aee06fb1355d3fa1561b3c5a4a/src-tauri/lu-core/src/agent_tool_loop.rs#L389). Browser reimplements the coordination, ordinary chat uses raw text/image inference. The present discovery function [native_capability_inventory.rs:70](https://github.com/vjmichael/Lu-AI-GUI/blob/11ffcbdb5a32e6aee06fb1355d3fa1561b3c5a4a/src-tauri/lu-core/src/native_capability_inventory.rs#L70) returns already registered + already granted tool names with `native_contract_registered_and_turn_granted_only`; the separate 13-entry static catalog at [lib.rs:9188](https://github.com/vjmichael/Lu-AI-GUI/blob/11ffcbdb5a32e6aee06fb1355d3fa1561b3c5a4a/lu-desktop/src-tauri/src/lib.rs#L9188) is neither availability nor authority. A model cannot consistently discover useful capabilities before resource authorization, and more source files do not automatically increase practical capability.

Proposed CP-05 contract: one host-owned turn identity and typed attachment/request; one intent decision (deterministic exact safe route or model selection); inventory with independent states implemented / installed+ready / eligible / granted / executed / independently verified; request exact resource approval only when necessary; same scoped registry/codec/policy/broker and supervised tool loop; structured error/observation returned to model; bounded re-evaluation, durable journal, native cancel/recovery and UI progress. Keep operation-specific security policy, least privilege, protected workers, precise scope and independent oracles. Browser may retain distinct specialized mechanics underneath shared orchestration; do not force all workers into identical transport or allow arbitrary shell. Never make retrieved instructions authority. Retire redundant routing switches only after matching behavior tests.

**C_practical = f(K,I,A,F):** K = model reasoning and source-bound memory; I = reachable real interfaces with honest availability; A = human-governed exact resources/effects; F = independent verified observations, feedback, recovery. No invented scalar weights. CP-09 uses same local model and equivalent tool authorization comparing model-only, direct tools and full Lu; record success and failure origin, unnecessary user interactions, tool choice/arguments, tokens/steps, time/CPU/GPU/RAM/VRAM, recovered tasks; no numerical uplift is claimed.
