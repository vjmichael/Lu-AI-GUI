## Root causes and follow-on work

1. **CP-06B — Scoped intent and model selection:** generic read questions offer eleven workspace/Git alternatives and the pinned small Qwen3 frequently abstains. Distinguish read-only uses of words such as `commit` from effect intent rather than remove the no-tools or write veto. Preserve optional null, original human bytes, human resource picker, typed live catalog and no fallback claim of a successful observation. Use adversarial compound/mutation/instruction prompts and controlled narrow read-only proposals; no path guessing or auto-dispatch. Browser/specialist selection has separate prerequisites.
2. **CP-06C — Result grounding and operation contracts:** `lu_check_env` native evidence explicitly reports `file_present_only`, `execution_verified=false`, `version=null`; the real answer says Git is installed. Enforce native verdict/evidence limitations in the model final boundary without silently injecting a result, and expand fixture-level oracles for file facts, search, discovery, archive manifest, artifact SHA and Git facts. Require observed result in observation-only fixtures, without globally forcing tools for plain chat. Independently verify cancellation/expiry/denial and no false completion.
3. **CP-06D — Existing human-confirmed effects:** nine typed effect paths run through a native reviewed dispatcher, not a generally advertised model mutation. Verify actual model inert proposal, native review, exact source and destination, no-clobber, durable receipt and same-turn or clearly scoped subsequent feedback. Do not turn model proposals into grants. Separate protected archive-worker acceptance remains mandatory.
4. **CP-06E — Resolve latent capability dispositions:** network fetch/academic leads, background controls/results, individual ZIP/ISO extraction, Linux archive creation/extraction, XLSX creation: either integrate via existing native admission/journal/oracle or explicitly document as unsupported/redundant. Current ordinary creation mode has only DOCX/PPTX. Do not casually expose latent writers or repeat an uncertain write. `lu_browser_interact` is intentionally withheld under read-only authorization, not a defect.
5. **CP-06F — Qualified and installed acceptance:** reviewed Git/media/PDF/image and Browser require independently pinned workers/source, provider/OS custody, fresh human consent and genuine native model observation. Local cgroup v2 mount is read-only; no positive protected execution is claimed. Then one grouped acceptance candidate, not per-tool CI or repeated installers. Physical Radeon/MMProj and all later work remain separate. Maintain the original safety and source bindings.

The audit covers the implementation of I (reachable interfaces), A (actual human-governed authority) and F (native feedback plus grounded final answer) in the user's C_practical = f(K,I,A,F) framework. Do not count registration, hypothetical availability, scripted model calls, or a successful native result without grounded meaning as practical model success.
