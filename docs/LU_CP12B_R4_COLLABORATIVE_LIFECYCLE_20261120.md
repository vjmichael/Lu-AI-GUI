# CP-12B-R4 — Collaborative diagnostic review lifecycle

Date: 2026-11-20 UTC. Local qualification, not a release.

## Changes

The review controller serializes the stop/commit decision so an accepted stop cannot produce a later accepted finding. An already committed result is not reported as cancelled. Foreground work can request cancellation; cancellation may reap the inference worker, requiring an explicit normal model reload. The receiver carries its cancellation signal into the authenticated v2 transport. Incomplete frames use a bounded total deadline. Cancellation or revocation cannot retract bytes already transmitted; authenticated one-use admission may consume an invitation before the receiver stops. Invitations do not confer model, tool, file, user-profile or remote-control authority. V1 wire compatibility remains unchanged; v2 remains Linux-only. UI guards prevent duplicate review requests and stale invitation refreshes.
