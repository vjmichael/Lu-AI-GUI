# CP-11B-R2 — initial scheduled tool scope

The first tool-authorized scheduled operation is an opt-in exact-line read of a literal user-pasted immutable note (2 KiB, 32 lines, selected nonempty line <=160 bytes). The installed native approval displays note, line, model, conversation, timing and 32-attempt limit. Legacy text-only schedules have no tool authority. The grant is atomically stored with the schedule; no path, URL, arbitrary argument, current chat data or general tool registry is admitted. No automatic model load or background service.

A genuine first model generation must return the exact command READ (surrounding whitespace ignored). The host checks owner/model/active occurrence, original scope digest and absence of previous receipt before executing the actual bounded Reader. A separate text split verifies selected text, character count and source identity. The receipt is committed before giving only the selected line to the second generation. Its normalized answer must exactly match the verified line; a missing or wrong result fails closed. Both phases share the existing 35-second deadline; foreground work can prevent the second phase. The source receipt persists even if inference is interrupted, and the terminal result is never promoted without comparison. No interrupted occurrence is replayed. Local scope/checksum integrity is not a cryptographic authentication of a hostile profile.

General scheduled mutable-file, network, write or external-effect operation, installed cross-platform custody, grant-management/upgrade tests and broader automation remain open. No Cognitum or arithmetic capability is duplicated.
