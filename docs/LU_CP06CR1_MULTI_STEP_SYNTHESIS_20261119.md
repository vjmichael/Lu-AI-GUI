This is a deliberate initial foreground bound, not scalable exhaustive corpus synthesis.

Invalid synthesis with usable evidence receives a labeled incomplete fallback; no evidence, cancellation/revocation or inference failure takes existing failure/terminal path rather than presenting a success.
