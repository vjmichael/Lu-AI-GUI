## 1. Findings

**21 distinct tool names with source-connected scoped model loops; 9 model-coded names executed through inspected host-confirmed typed dispatch routes (not automatically model-advertised); 12 additional named codec registrations explicitly withheld or without a demonstrated production-model entrypoint in the reviewed paths.** 42 concrete named codec definitions inventoried, counted once across multiple lanes. Not a claim that there are exactly 42 possible tools in the whole repository: dynamic extension names, generic host-reviewed registration, and any undiscovered caller/registration remain separate. The 21 are a union across distinct, separately authorized lanes, never one global grant. No runtime delivery/installed dependencies proven.

The generic normal Send uses direct text/image inference, with exact host phrase matching to switch to specialized lanes and inert JSON proposals for native mutations. Therefore the largest missing link is not additional parsers or worker implementations: it is general model discovery -> resource selection/authorization -> shared dispatch -> observation -> next decision. Retain existing source-level protection.
