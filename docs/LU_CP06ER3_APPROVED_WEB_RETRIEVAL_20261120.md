- `Search academic literature for Koine Greek` or `Find academic papers about Koine Greek` (one first-page OpenAlex discovery request)

No redirects, credentials, alternate transport, unapproved pagination, repeat dispatch or automatic retry. No grant survives restart. Existing curl cancellation flag is connected; cancelled DNS resolution cannot launch curl after it returns. The system resolver may itself block; cancellation/deadline behavior during real DNS resolution and external worker lifecycle remain acceptance requirements.

The response uses existing bounded HTTPS and public address policy. Direct UTF-8 fetches must have a successful 200 response and no redirect. Complete text is rehashed at the typed boundary; a truncated projection retains the whole-response digest and explicit limitation. Academic results preserve provider digest and unverified status; bounded display clearly states omitted leads and other pages. Both use the existing exact-observation presentation or explicitly labeled host fallback; model cannot convert catalog discovery into verified citations. No automatic source ingestion, content execution, citation approval, or research campaign is introduced. This initial route does not implement unrestricted natural-language query generation, multi-page browsing, or full article/PDF extraction.
