# IDE-MERGE-02C Windows Tauri native-dialog icon build repair

Original unchanged-head Windows LLVM18 run #43763652497, job #132963800362, failed at `ide/llvm18_owner/Test-PinnedOwnerWindows.ps1` when a direct `cargo check --manifest-path ide/app/src-tauri/Cargo.toml --features dev046d-native-dialog` invoked Tauri's real Windows resource compiler. The source checkout had no `ide/app/src-tauri/icons/icon.ico`. Rust diagnostic: `icons/icon.ico not found; required for generating a Windows Resource file during tauri-build`.

This was **not** an LLVM18 compiler failure: source-pinned LLVM18 compiled and original host/LLDB/DAP test groups passed earlier in that run. The subsequent native SCM owner-events step never attained positive acceptance.

Root cause: first-party `ide/app/scripts/make-icon.mjs` created icons only as a side effect of `npm run build`. The direct Tauri Cargo build does not run that npm script. The integration workflow's conditional `make_g04d_ci_icon.py` fallback instead used an explicitly **test-only, NOT release-reviewed 32×32 icon**, not acceptable as installed UI evidence.

- Commit actual first-party 64×64 `icons/icon.ico` and `icons/icon.png` bytes, generated by existing deterministic script **without network, extra packages or external artwork**. - New `verify_reviewed_ide_icons.py` checks **real Git HEAD blobs and remeasured raw image bytes**, rejects absent/untracked/linked/changed ICO/PNG and requires real 64×64 Windows resource format. It **never writes/generates** icons.
- The pinned Windows owner test retains the **same** direct `cargo check --features dev046d-native-dialog` with the preflight provenance test immediately before it; all original host SCM and DAP tests, original restricted service sequence and cleanup assertions remain.
- The consolidated Windows/Linux native source test and installed NSIS preflight now run the same verifier instead of silently generating the source-only G04D image. `npm run build` may regenerate these reviewed image bytes from the same checked-in generator; Node regression compares exact generated ICO/PNG to the committed assets.
